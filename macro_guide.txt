----------------------------------------------------------------
  V1 — 고정 좌표 매크로 (macro_v1_coordinate.py)
----------------------------------------------------------------

[ 핵심 원리 ]
화면의 특정 위치(좌표)를 미리 기록해두고,
그 위치를 순서대로 자동으로 클릭하는 방식입니다.

[ 동작 흐름 ]
1. 사용자가 클릭하고 싶은 좌석의 화면 좌표(X, Y)를 등록한다.
   - Capture 버튼: 3초 카운트다운 후 현재 마우스 위치를 자동 기록
   - Add Manual: 직접 숫자로 입력
2. START를 누르면 등록된 좌표를 하나씩 순서대로 클릭한다.
3. 클릭 후 이름을 붙여넣기(Ctrl+V)하고 Enter를 눌러 제출한다.

[ 사용 라이브러리 ]
- pyautogui : 마우스 클릭, 키보드 입력 자동화
- pyperclip : 클립보드에 이름 복사 (한글 입력 오류 방지)

[ 한계 ]
- 좌표는 내 화면 해상도/창 위치 기준이므로,
  창을 움직이거나 스크롤하면 좌표가 틀어진다.
- 이미 점령된 좌석을 등록해두면 헛클릭이 된다.
- 사전에 좌표를 일일이 등록해야 하는 번거로움이 있다.


----------------------------------------------------------------
  V2 — 이미지 인식 매크로 (macro_v2_image.py)
----------------------------------------------------------------

[ 핵심 원리 ]
"빈 좌석이 화면에 어떻게 생겼는지" 이미지로 저장해두고,
그 이미지와 일치하는 위치를 화면에서 실시간으로 찾아 클릭합니다.
좌표를 직접 지정하지 않고, 시각적으로 좌석을 인식합니다.

[ 동작 흐름 ]
1. 빈 좌석 이미지(참조 이미지)를 생성한다.
   - 웹 CSS 색상 그대로 28x28px 이미지를 코드로 자동 생성
   - Windows 화면 배율(100%/125%/150%)에 맞게 크기를 조정
2. START를 누르면 화면 전체를 스캔해 참조 이미지와 닮은 부분을 찾는다.
3. 발견하면 해당 위치를 클릭하고, 이름을 입력해 제출한다.
4. 다시 화면을 스캔해 다음 빈 좌석을 찾는다 (반복).
5. 빈 좌석이 5번 연속 발견되지 않으면 자동 종료한다.

[ 사용 라이브러리 ]
- pyautogui : 화면 스캔(locateOnScreen), 마우스/키보드 제어
- Pillow (PIL) : 참조 이미지 파일 생성
- pyperclip : 클립보드 복사

[ V1과의 차이 ]
- 좌표를 미리 등록할 필요 없이 자동으로 빈 좌석을 찾는다.
- 창 위치가 바뀌어도 화면을 다시 스캔하므로 더 유연하다.

[ 한계 ]
- 화면 배율 설정이 다르면 이미지 크기가 달라져 인식 실패.
  (Generate 버튼으로 현재 배율에 맞게 재생성 필요)
- 화면에 다른 창이 겹쳐 있으면 인식 오류 발생 가능.
- 매번 전체 화면을 스캔하므로 V3에 비해 속도가 느리다.


----------------------------------------------------------------
  V3 — HTML 태그 기반 매크로 (macro_v3_tag.py)
----------------------------------------------------------------

[ 핵심 원리 ]
화면을 "눈으로 보는" 것이 아니라,
웹페이지의 HTML 코드를 직접 읽어서 빈 좌석을 찾습니다.
Selenium이 브라우저를 직접 제어하므로
화면 해상도, 창 크기, 배율과 완전히 무관합니다.

[ 동작 흐름 ]
1. Selenium이 Chrome 브라우저를 자동으로 열고 사이트에 접속한다.
2. HTML에서 CSS 클래스가 "seat"이면서 "claimed"도 "inactive"도
   아닌 요소들을 모두 찾는다. (= 빈 좌석)
   → CSS 셀렉터: .seat:not(.claimed):not(.inactive)
3. 찾은 빈 좌석 중 하나를 무작위로 선택해 JavaScript로 클릭한다.
4. 이름 입력 모달이 열렸는지 확인 후, JavaScript로 이름을 입력하고
   confirmName() 함수를 직접 호출해 제출한다.
5. 2~4를 빈 좌석이 없을 때까지 반복한다.

[ 사용 라이브러리 ]
- selenium : 브라우저 자동화 (Chrome WebDriver)

[ V1, V2와의 차이 ]
- 화면을 전혀 보지 않는다. HTML 구조를 파싱해 직접 제어한다.
- 속도가 가장 빠르고 정확하다.
- 웹사이트 구조(클래스명, 함수명)를 알고 있어야 작성 가능하다.
- 화면이 최소화되어 있어도 동작한다.

[ 한계 ]
- 웹사이트가 구조를 바꾸면(클래스명 변경 등) 매크로가 작동 안 한다.
- Selenium + ChromeDriver 설치가 필요하다.
- 브라우저를 직접 띄우기 때문에 탐지될 위험이 상대적으로 높다.

  V3 심화 — CSS 셀렉터 완전 이해
  F12 개발자 도구로 직접 탐색하기

----------------------------------------------------------------
  1. CSS 셀렉터란?
----------------------------------------------------------------

HTML 문서에서 "특정 조건에 맞는 요소"를 골라내는 문법입니다.
원래는 CSS 스타일을 입힐 때 쓰지만,
Selenium에서도 같은 문법으로 요소를 찾을 수 있습니다.

예시:
  .seat                     → class에 "seat"가 있는 모든 요소
  .seat.claimed             → class에 "seat"와 "claimed"가 모두 있는 요소
  .seat:not(.claimed)       → class에 "seat"는 있지만 "claimed"는 없는 요소


----------------------------------------------------------------
  2. 이 사이트에서 좌석 HTML이 어떻게 생겼나?
----------------------------------------------------------------

브라우저가 10000개 좌석을 이렇게 만들어 놓습니다:

  [ 빈 좌석 ]
  <div class="seat" id="seat-0" data-num="1"></div>

  [ 점령된 좌석 ]
  <div class="seat claimed" id="seat-42" data-num="43"
       style="background: #e94560;" data-owner="홍길동"
       title="홍길동"></div>

  [ 비활성 좌석 (게임 중지 상태) ]
  <div class="seat inactive" id="seat-99" data-num="100"></div>

핵심은 class 속성입니다.
  - 아무것도 없으면 → 클릭 가능한 빈 좌석
  - claimed 추가    → 이미 누군가 점령
  - inactive 추가   → 게임이 꺼져있어서 클릭 불가


----------------------------------------------------------------
  3. V3 코드의 셀렉터 분해
----------------------------------------------------------------

코드:
  seats = driver.find_elements(By.CSS_SELECTOR,
              ".seat:not(.claimed):not(.inactive)")

이걸 하나씩 읽으면:

  .seat              → class="seat" 인 요소를 찾아라
  :not(.claimed)     → 단, class에 "claimed"가 있는 건 제외해라
  :not(.inactive)    → 단, class에 "inactive"가 있는 것도 제외해라

결과: class가 정확히 "seat" 하나뿐인 요소들 = 빈 좌석만


----------------------------------------------------------------
  4. F12 개발자 도구로 직접 확인하기
----------------------------------------------------------------

[ STEP 1. 개발자 도구 열기 ]

  사이트 접속 후 F12 또는 Ctrl+Shift+I
  → 오른쪽(또는 아래)에 개발자 도구 패널이 열립니다.


[ STEP 2. Elements 탭에서 HTML 구조 보기 ]

  상단 탭에서 "Elements" 클릭
  Ctrl+F 를 누르면 HTML 내에서 검색창이 열립니다.

  검색창에 입력:
    seat-0
  → id="seat-0" 인 첫 번째 좌석 요소로 이동

  좌석을 클릭했다 점령했다 하면서 Elements 탭을 보면
  class 속성이 실시간으로 바뀌는 것을 확인할 수 있습니다:
    클릭 전:  class="seat"
    클릭 후:  class="seat claimed"


[ STEP 3. 내가 원하는 요소 직접 클릭해서 확인하기 ]

  개발자 도구 왼쪽 상단의 커서 아이콘(화살표) 클릭
  또는 Ctrl+Shift+C

  그 상태로 웹페이지의 좌석 위에 마우스를 올리면
  → Elements 탭이 그 요소로 자동 이동하면서 HTML을 보여줍니다.

  예시로 빈 좌석 위에 올리면:
    <div class="seat" id="seat-7" data-num="8"></div>

  이미 점령된 좌석 위에 올리면:
    <div class="seat claimed" id="seat-7" style="background: #74b9ff;"
         data-owner="민준" title="민준"></div>


[ STEP 4. Console 탭에서 셀렉터 직접 테스트하기 ]

  상단 탭에서 "Console" 클릭
  아래 명령어를 직접 입력해서 테스트할 수 있습니다.

  ▶ 빈 좌석 전체 개수 확인:
    document.querySelectorAll('.seat:not(.claimed):not(.inactive)').length

  ▶ 빈 좌석 첫 번째 요소 확인:
    document.querySelector('.seat:not(.claimed):not(.inactive)')

  ▶ 점령된 좌석 개수 확인:
    document.querySelectorAll('.seat.claimed').length

  ▶ 비활성 좌석 개수 확인:
    document.querySelectorAll('.seat.inactive').length

  Enter를 치면 즉시 결과가 나옵니다.
  Selenium의 find_elements는 이 querySelectorAll과 동일하게 동작합니다.


[ STEP 5. 셀렉터 바꿔가며 실험해보기 ]

  Console에서 다양하게 테스트:

  // 모든 좌석
  document.querySelectorAll('.seat').length

  // 빈 좌석만
  document.querySelectorAll('.seat:not(.claimed):not(.inactive)').length

  // 점령된 좌석의 주인 이름 목록
  [...document.querySelectorAll('.seat.claimed')].map(s => s.dataset.owner)

  // 특정 이름이 점령한 좌석 찾기
  [...document.querySelectorAll('.seat.claimed')]
    .filter(s => s.dataset.owner === '홍길동')


----------------------------------------------------------------
  5. V3 코드가 실제로 하는 일 (단계별)
----------------------------------------------------------------

  [ 1단계 ]
  Selenium이 Chrome을 열고 사이트에 접속
    → driver = webdriver.Chrome()
    → driver.get(SITE_URL)

  [ 2단계 ]
  HTML에서 빈 좌석 요소 전부 수집
    → seats = driver.find_elements(By.CSS_SELECTOR,
                  ".seat:not(.claimed):not(.inactive)")
    → 이 시점에 빈 좌석이 200개면 seats 리스트에 200개 담김

  [ 3단계 ]
  그 중 랜덤으로 하나 선택
    → seat = random.choice(seats)

  [ 4단계 ]
  JavaScript로 그 요소를 클릭
    → driver.execute_script("arguments[0].click();", seat)
    → pyautogui처럼 화면 좌표가 아니라, 요소 객체를 직접 클릭

  [ 5단계 ]
  이름 입력 모달이 열렸는지 확인하고 이름 주입
    → document.getElementById('name-input').value = "이름"
    → window.confirmName()  ← 사이트 내부 함수를 직접 호출!

  [ 6단계 ]
  delay 만큼 대기 후 2단계로 돌아가 반복


----------------------------------------------------------------
  6. "왜 JavaScript로 클릭하나?" — execute_script 이해
----------------------------------------------------------------

Selenium에는 두 가지 클릭 방법이 있습니다:

  방법 A: seat.click()
    → Selenium이 브라우저에게 "이 위치를 클릭해줘"라고 요청
    → 요소가 화면 밖에 있거나 다른 요소에 가려지면 실패할 수 있음

  방법 B: driver.execute_script("arguments[0].click();", seat)
    → 브라우저 내부 JavaScript 엔진이 직접 click 이벤트를 발생
    → 화면에 안 보여도, 스크롤 밖에 있어도 작동
    → V3에서는 10000개 중 어느 위치든 동작해야 하므로 이 방법 사용
